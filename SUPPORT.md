## Before filing

1. Confirm version **1.1.0** on the extension card (Reload ↻ after updating).
2. Try a clean profile with only markClipper enabled.
3. Collect: browser + OS, the URL (or a similar one), console log (`F12` on the panel).

## Quick fixes

| Symptom | Fix |
|---|---|
| Icon click does nothing | Pin the icon; ensure no other extension hijacks the panel |
| Empty article clip | Site is JS-heavy — try Full or Selection mode |
| Photos tab empty | Page may lazy-load on scroll — scroll, then re-grab |
| Download blocked | Check the browser's automatic downloads permission |
| `file://` pages | Extensions cannot inject there — bookmark fallback only |
