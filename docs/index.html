Install in 30 seconds

Chrome, Edge, Brave, Opera, Arc, Vivaldi, Yandex.

1. Download the release ZIP (or git clone https://github.com/Ahmedbakr78/Heros_Note.git).
2. Open chrome://extensions and enable Developer mode.
3. Load unpacked → select the Heros_Note folder (contains manifest.json).
4. Pin markClipper, click it — the side panel opens. No popup, ever.
5. Optional: chrome://extensions/shortcuts — defaults Ctrl+Shift+K panel, A article, S selection, B bookmark, I photos, P shot.

Keyboard-first

Ctrl+Shift+A — clip article
Ctrl+Shift+S — clip selection
Ctrl+Shift+B — bookmark
Ctrl+Shift+I — grab photos
Ctrl+Shift+P — screenshot

Questions

Full 30-question list in the README.

Is it really free?

Yes — MIT, unlimited clips, photos and exports. No accounts, no quotas.

Where do my notes live?

chrome.storage.local in your browser profile. Backup exports one JSON file you own.

Why panel-only?

The page stays visible; your selection and focus are never stolen by a popup window.

How many images can it grab?

Up to 250 per page, with hi-res srcset resolution, dedupe, filters and bulk download.

Obsidian-compatible?

Yes — YAML frontmatter + GFM Markdown drop straight into a vault.
