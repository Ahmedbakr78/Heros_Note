# Changelog — markClipper

## 1.1.0 — Photo Lab max power
- New **Photos tab**: grab up to 250 images/page (img, picture/srcset, data-src, lazy, og:image, CSS hero backgrounds), hi-res URLs, dedupe.
- Photo grid: tap-select, All/None, min-width slider, hide-icons, caption search, 3 sorts, WxH badges, lazy + debounced 60fps.
- Lightbox: fullscreen, prev/next, copy MD, download, open original, double-click to open.
- Gallery clips: `### Photo N + image + caption + original` Markdown, photo counts, bulk download via chrome.downloads, copy gallery MD.
- Screenshot: visible-tab PNG/JPEG, in-panel preview, downscaled 1100px embed (quota-safe), save as self-contained clip, download original.
- Single-photo clip from right-click with caption + source link.
- Preview renders photos as real thumbnails (figure/img).
- Settings: hi-res, skip icons/avatars, skip data-URLs, backgrounds, captions, min width, shot format.
- Menus/keys: Grab photos, Screenshot, Download photo; Ctrl+Shift+I photos, Ctrl+Shift+P shot.
- In-app feature list now 90+ items incl. 26-photo group. Stats add photos grabbed + images in notes.
- Design still full Heros_PDF copy. Protected dirs untouched.

## 1.0.0 — Panel launch
- New app: **markClipper — Markdown Web Clipper**, panel-only (action opens side panel, no popup/tab app).
- Design: full Heros_PDF system copy — theme tokens, floating topbar, pill tabs, ultra-rounded cards, status bar, toasts, menu, modal, chips, toggles.
- Capture: article / full / selection / bookmark / link / image, re-clip, context menus, 4 keyboard commands, blocked-page bookmark fallback.
- Perfect Markdown: headings, emphasis, ==mark==, links (absolute), images, code fences, GFM tables, tasks, quotes, details, YAML frontmatter, filename templates.
- Library: search, type/star/tag filters, 4 sorts, star/copy/delete, preview/source/details, edit, title+tags, .md/.html/.txt/.json export, bulk export.
- Power: per-clip notes, todos, stats (clips/words/sites/streak), widths, font scale, dark/light/system, backup/restore/wipe.
- In-app **All features list** modal (50+ items) + shortcuts modal.
- Private/fast/free/unlimited: local-only storage, zero deps, CSP self.
